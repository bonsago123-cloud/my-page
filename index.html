네트워크 — 용어를 구조와 연결해 이해하기

상황: WAN, 게이트웨이, 사설 IP처럼 비슷해 보이는 개념을 공부할 때 혼동이 생겼습니다.

행동: 각 장치가 패킷을 어디로 보내는지 그림과 예제로 다시 정리했습니다.

결과: LAN/WAN과 기본 게이트웨이의 역할을 서로 구분해 설명할 수 있게 되었습니다.

강점과 취향을 보여주는 근거 3개

1. 모르면 원리까지 묻기

상황
외운 정의만으로는 네트워크 개념이 서로 충돌해 보였습니다.
행동
IP, 서브넷, 게이트웨이를 실제 패킷 이동 순서로 다시 질문하고 정리했습니다.
결과
“같은 스위치”와 “같은 IP 네트워크”가 다른 개념임을 구분했습니다.

2. 직접 실행해서 확인하기

상황
Python 문법을 읽기만 하면 결과를 예상하기 어려웠습니다.
행동
작은 예제를 직접 실행해 조건문, 함수, 자료형의 동작을 비교했습니다.
결과
예제의 출력값을 보고 문법 설명과 실제 동작을 연결할 수 있게 되었습니다.

3. 개념끼리 연결하기

상황
선형대수의 rank, basis, column space가 각각 따로 느껴졌습니다.
행동
하나의 행렬 예제에서 세 개념이 어떻게 이어지는지 단계별로 비교했습니다.
결과
pivot column이 column space의 basis와 연결되는 이유를 설명할 수 있게 되었습니다.

왜 공개하지 않나요?

이 페이지의 목적은 나의 학습 방식과 관심사를 보여주는 것이므로, 목적과 직접 관계없는 개인정보나 인증 정보는 공개할 필요가 없다고 판단했습니다.

짧은 확인 방법

  1. 어디로 가나요? 공개 배포된 결과물 주소로 이동합니다.
  2. 3단계 이내 무엇을 하나요? 페이지 접속 → Tab으로 Python 버튼 이동 → Enter를 누릅니다.
  3. 무엇이 보이면 통과인가요? Python 버튼이 선택되고 아래 내용이 Python 근거로 바뀝니다.
  4. 안 될 때 무엇이 보이나요? 선택 표시나 설명 내용이 바뀌지 않으면 실패입니다.

AI와 나의 판단
