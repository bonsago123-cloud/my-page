## 검증 범위

업로드한 사진은 패스키 취소, 마지막 패스키 삭제 UI 차단, 패스키 두 개 등록, 로그아웃, 남은 패스키로 로그인 성공 등을 보여줍니다. `05_계정명_오입력_404_보조자료.png`는 **삭제된 패스키의 인증 실패를 증명하는 자료가 아닙니다**. 계정 이름과 패스키 별명은 구분해야 합니다.

별도 시험 계정 A/B를 실제 배포 Vercel API에서 인증 후 타인 자료 요청 HTTP 403, 사용한 챌린지 재사용 HTTP 409, 변조된 서명 HTTP 401 및 로그아웃 세션 재사용 HTTP 401 결과를 기록했습니다. 시험용 소프트웨어 키쌍을 사용했으며 Windows Hello 실물 기기 시험과 혼동하지 않습니다.
