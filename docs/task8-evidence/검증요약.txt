과제 8 검증 요약 — 2026-11-18

사용자 사진 6장: 등록 취소, 마지막 삭제 UI 차단, 패스키 두 개 등록, 로그아웃, 로그인 성공 등
실운영 HTTP: 무인증 GET /api/private → 401; A/B 시험 계정 2개 실제 WebAuthn 등록(201), 정상 서명 로그인(200), 재사용 차단(409), 서명 변조 차단(401), 교차 접근 양방향(403/403), 마지막 키 삭제 차단(409), 로그아웃 세션 재사용 차단(401).
사용자 직접 확인: 삭제한 패스키 인증 실패(단, 네트워크 캡처 없음).
한계: 시험 계정의 서명은 컴퓨터 생성 P-256 키이며 실물 Windows Hello UI를 사용하지 않음.
